## 📖 About the Project

**KNIPSS Campus** is a modern web-based campus platform built to provide a centralized digital experience for students and the academic community of **Kamla Nehru Institute of Physical and Social Sciences (KNIPSS)**.

The project focuses on creating a clean, responsive, and interactive campus experience using modern frontend technologies.

The application is built using **React 19 and TypeScript**, with **Vite** providing a fast development and build environment. Tailwind CSS is used for responsive styling, while Motion and Lucide React enhance the user interface and interactions.

The project also integrates the **Google Gemini API** to support AI-powered functionality within the campus ecosystem.
